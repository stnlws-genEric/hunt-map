Sync

Keeps your pins, trails and sits level across devices through a private GitHub repo you own. The map itself ships with the app, so only your own work travels. Nothing is public and nothing costs money.

The token is stored on this device only and never leaves it except to talk to GitHub. If you lose this device, revoke the token on github.com and it is dead.
